Objetivo: Desenvolver uma plataforma que permita registrar e gerenciar objetos encontrados ou abandonados no campus do IFRN, auxiliando os estudantes a encontrar seus pertences de maneira mais fácil.

Tecnologias utilizadas:

Pré-requisitos:

node (versão recente)

Instalação de dependências:

Abra o terminal e digite o seguinte comando abaixo para executar o projeto corretamente:
npm install
npm start
